# Linux System Administration Lab

## Objective
Hands-on practice in Linux administration and basic troubleshooting using Termux.

## Skills Practised
- Linux command-line navigation
- File and directory management
- File permissions
- Process management
- Disk usage monitoring
- Network troubleshooting
- Service management concepts
- Log analysis
- Backup and recovery
- Bash scripting

## Automation Scripts
- system-check.sh
- disk-monitor.sh

## Environment
- Android device
- Termux
- Bash
- Git
- Python

## Project Status
Beginner-level practical lab. Commands and exercises are documented as completed.
